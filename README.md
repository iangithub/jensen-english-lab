# Clear English Lab

A static bilingual English-learning site for clear spoken English practice.

## What it includes

- Speaking analysis: high-frequency words, clean SVO structure, repetition, listener buffers, low-idiom English, and clear framing.
- Topic sentence bank: English and Traditional Chinese sentence cards for basic real-world conversation.
- Common word bank: core words grouped by use case, with short sample sentences.
- Conversation flow: a complete basic communication path from greeting to closing.
- Audio playback: browser Web Speech API, so no API key is exposed in frontend code.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Verification

```bash
npm install
npm run verify
```
